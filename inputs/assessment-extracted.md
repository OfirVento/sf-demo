2. **Adoption is the dominant story, not complexity.** 345 licenses, 6 active users, 0 quotes in 90 days, 23 all-time. The report repeatedly notes "low transaction volume may underrepresent operational complexity signals."
3. **All CPQ plugin slots are unset.** 14 plugin Apex classes EXIST in the org but NONE are registered. The QCP scripts (5) similarly aren't activated via package settings. The pricing logic actually running today is standard CPQ + price rules + product rules.

7. **No real concerns/audience-framing in the report.** This is a *current-state assessment*, not a migration recommendation. Concerns, LOE, RCA opportunities, expansion signals, audience narratives — these are all things WE synthesized, not things the report contains.
